ChartDB is an open-source tool that turns a database schema into an interactive diagram. Developers self-host it for free, and a paid cloud version adds hosting and team features ([source](../sources/7vz6b_Ohdl0.md), [1:04](https://www.youtube.com/watch?v=7vz6b_Ohdl0&t=64s), [13:46](https://www.youtube.com/watch?v=7vz6b_Ohdl0&t=826s)).

## What it is

- It needs no sign-up, no database access and no install. The user runs one "smart query" in their own client and pastes the JSON result ([source](../sources/7vz6b_Ohdl0.md), [3:27](https://www.youtube.com/watch?v=7vz6b_Ohdl0&t=207s)).
- Stack: React, Vite, Node.js, Tailwind and React Flow for the canvas ([source](../sources/7vz6b_Ohdl0.md), [10:42](https://www.youtube.com/watch?v=7vz6b_Ohdl0&t=642s)).
- The auto captions often spell it "Chartbrew" or "Charted Be". The video description confirms ChartDB.

## Founders

- [Jonathan Fishner](../people/jonathan-fishner.md), a developer and co-founder ([source](../sources/7vz6b_Ohdl0.md), [1:04](https://www.youtube.com/watch?v=7vz6b_Ohdl0&t=64s)).

## Business model

- Open core. Free downloads are the funnel, and a small group pays for the hosted cloud version ([source](../sources/7vz6b_Ohdl0.md), [13:46](https://www.youtube.com/watch?v=7vz6b_Ohdl0&t=826s), [14:41](https://www.youtube.com/watch?v=7vz6b_Ohdl0&t=881s)).
- It was free at first. Users asked for team use, so real-time collaboration became the paid feature ([source](../sources/7vz6b_Ohdl0.md), [8:39](https://www.youtube.com/watch?v=7vz6b_Ohdl0&t=519s)).
- Monthly tools (2026-02): AWS $600, a SOC 2 compliance tool $500, Claude Code Max $200, ChatGPT $20 plus about $50 in API tokens, Framer $30, analytics $25 ([source](../sources/7vz6b_Ohdl0.md), [10:42](https://www.youtube.com/watch?v=7vz6b_Ohdl0&t=642s)).

## Metrics

- About $9K MRR, almost $9,400, 16 months after the open-source launch (2026-02) ([source](../sources/7vz6b_Ohdl0.md), [1:04](https://www.youtube.com/watch?v=7vz6b_Ohdl0&t=64s), [2:19](https://www.youtube.com/watch?v=7vz6b_Ohdl0&t=139s)).
- Over 21K GitHub stars and 250K developers who used it in the year (2026-02) ([source](../sources/7vz6b_Ohdl0.md), [1:36](https://www.youtube.com/watch?v=7vz6b_Ohdl0&t=96s)).

## Growth channels

- **Show HN.** It launched on Hacker News after 3 weeks of development and reached the front page. Thousands of engineers came on the first day ([source](../sources/7vz6b_Ohdl0.md), [3:55](https://www.youtube.com/watch?v=7vz6b_Ohdl0&t=235s), [4:42](https://www.youtube.com/watch?v=7vz6b_Ohdl0&t=282s)).
- **Why it worked.** Developers can test open source with no sign-up. A unique wedge earns upvotes ([source](../sources/7vz6b_Ohdl0.md), [4:51](https://www.youtube.com/watch?v=7vz6b_Ohdl0&t=291s)).
- **Developer channels.** GitHub, Hacker News and self-hosted subreddits ([source](../sources/7vz6b_Ohdl0.md), [8:39](https://www.youtube.com/watch?v=7vz6b_Ohdl0&t=519s)).

## Timeline

- First idea: an AI database client. It failed because users had to give credentials and install software to a tool they did not trust ([source](../sources/7vz6b_Ohdl0.md), [2:26](https://www.youtube.com/watch?v=7vz6b_Ohdl0&t=146s)).
- Pivot: a low-friction diagram tool, built in 3 weeks and launched on Show HN ([source](../sources/7vz6b_Ohdl0.md), [3:55](https://www.youtube.com/watch?v=7vz6b_Ohdl0&t=235s)).
- 2026-02: about $9K MRR ([source](../sources/7vz6b_Ohdl0.md), [1:04](https://www.youtube.com/watch?v=7vz6b_Ohdl0&t=64s)).

## Lessons

- "Start with a wedge and not from the full vision" ([source](../sources/7vz6b_Ohdl0.md), [7:38](https://www.youtube.com/watch?v=7vz6b_Ohdl0&t=458s)).
- The team ignored everything else and made database visualization obvious. Then growth started ([source](../sources/7vz6b_Ohdl0.md), [11:57](https://www.youtube.com/watch?v=7vz6b_Ohdl0&t=717s)).
