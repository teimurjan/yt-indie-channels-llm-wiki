This page collects what the sources say about Cursor Directory, a website that collects Cursor rules and MCP servers.

## What it is

Cursor Directory collects rules for the Cursor code editor in one place. Before it, rules lived in scattered gists and forums ([LWPN-PAhtLA](../sources/LWPN-PAhtLA.md), [3:21](https://www.youtube.com/watch?v=LWPN-PAhtLA&t=201s)).

## Founders

- [Pontus Abrahamsson](../people/pontus-abrahamsson.md) and his friend Victor built it. They also run the bootstrapped startup Midday ([LWPN-PAhtLA](../sources/LWPN-PAhtLA.md), [0:17](https://www.youtube.com/watch?v=LWPN-PAhtLA&t=17s)).

## Business model

- Revenue comes from paid job listings and paid featured MCP listings ([LWPN-PAhtLA](../sources/LWPN-PAhtLA.md), [10:16](https://www.youtube.com/watch?v=LWPN-PAhtLA&t=616s)), ([LWPN-PAhtLA](../sources/LWPN-PAhtLA.md), [11:05](https://www.youtube.com/watch?v=LWPN-PAhtLA&t=665s)).
- Running costs are about $525/month. Upkeep is about 3 hours a month, because the rules are open source and merged on GitHub ([LWPN-PAhtLA](../sources/LWPN-PAhtLA.md), [11:55](https://www.youtube.com/watch?v=LWPN-PAhtLA&t=715s)).
- The stack is Next.js, TypeScript, shadcn, Resend, OpenPanel, Vercel and Polar ([LWPN-PAhtLA](../sources/LWPN-PAhtLA.md), [11:55](https://www.youtube.com/watch?v=LWPN-PAhtLA&t=715s)).

## Metrics

- About $34K to $35K/month at a 99.8% gross margin (2025-11) ([LWPN-PAhtLA](../sources/LWPN-PAhtLA.md), [2:39](https://www.youtube.com/watch?v=LWPN-PAhtLA&t=159s)).
- 49,000 registered users and 2.2M unique visitors since launch (2025-11) ([LWPN-PAhtLA](../sources/LWPN-PAhtLA.md), [2:39](https://www.youtube.com/watch?v=LWPN-PAhtLA&t=159s)).
- One launch post on X got about 1M impressions ([LWPN-PAhtLA](../sources/LWPN-PAhtLA.md), [5:43](https://www.youtube.com/watch?v=LWPN-PAhtLA&t=343s)).

## Growth channels

- **Build in public on X**, with fully open-source code ([LWPN-PAhtLA](../sources/LWPN-PAhtLA.md), [5:43](https://www.youtube.com/watch?v=LWPN-PAhtLA&t=343s)).
- **Hacker News**. The launch reached the front page, and YouTubers then covered it ([LWPN-PAhtLA](../sources/LWPN-PAhtLA.md), [5:43](https://www.youtube.com/watch?v=LWPN-PAhtLA&t=343s)).
- **New features for each new wave**. An MCP section and a rules generator brought a second burst of adoption ([LWPN-PAhtLA](../sources/LWPN-PAhtLA.md), [11:05](https://www.youtube.com/watch?v=LWPN-PAhtLA&t=665s)).
- **Design as a moat**. Pontus says AI-made websites all look the same ([LWPN-PAhtLA](../sources/LWPN-PAhtLA.md), [6:58](https://www.youtube.com/watch?v=LWPN-PAhtLA&t=418s)).

## Timeline

- On a 3-hour flight to France, Pontus spots the gap ([LWPN-PAhtLA](../sources/LWPN-PAhtLA.md), [3:21](https://www.youtube.com/watch?v=LWPN-PAhtLA&t=201s)).
- After landing, they build it in about 3 hours. It is on Vercel within about 30 minutes, with a hard-coded JSON file of rules ([LWPN-PAhtLA](../sources/LWPN-PAhtLA.md), [3:50](https://www.youtube.com/watch?v=LWPN-PAhtLA&t=230s)).
- Launch: about 1M impressions on X and the Hacker News front page ([LWPN-PAhtLA](../sources/LWPN-PAhtLA.md), [5:43](https://www.youtube.com/watch?v=LWPN-PAhtLA&t=343s)).
- 2025-11: About $34K to $35K/month ([LWPN-PAhtLA](../sources/LWPN-PAhtLA.md), [2:39](https://www.youtube.com/watch?v=LWPN-PAhtLA&t=159s)).
