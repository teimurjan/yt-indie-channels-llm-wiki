# Figma

Figma is a collaborative design tool for UI, web and app design. Almost every design video in the wiki uses it, and most of them are tutorials by [Tim Gabe](../people/tim-gabe.md).

## What it is

- A general design tool that runs in the browser or as a desktop app ([blDSmD5I61s](../sources/blDSmD5I61s.md), [1:38](https://www.youtube.com/watch?v=blDSmD5I61s&t=98s)).
- Tim Gabe's analogy: Figma draws the blueprint and [Framer](framer.md) builds the building. A developer or another tool must still build the app or site ([XPim-a5R6yw](../sources/XPim-a5R6yw.md), [0:16](https://www.youtube.com/watch?v=XPim-a5R6yw&t=16s)). Keep Figma for graphics, apps and dashboards ([XPim-a5R6yw](../sources/XPim-a5R6yw.md), [0:56](https://www.youtube.com/watch?v=XPim-a5R6yw&t=56s)).
- Core features that the tutorials cover:
  - **Auto layout**, Figma's version of CSS flexbox ([Kf8L3CeiWzQ](../sources/Kf8L3CeiWzQ.md), [0:22](https://www.youtube.com/watch?v=Kf8L3CeiWzQ&t=22s)). See [Auto layout](../topics/auto-layout.md).
  - **Constraints and resizing**, which set how a child reacts to a size change of its parent frame ([3xGJ80UpVeM](../sources/3xGJ80UpVeM.md), [6:02](https://www.youtube.com/watch?v=3xGJ80UpVeM&t=362s)).
  - **Component properties**: variants, instance swap, text and boolean ([iaQ30m6gqhw](../sources/iaQ30m6gqhw.md), [0:12](https://www.youtube.com/watch?v=iaQ30m6gqhw&t=12s)).
  - **Interactive components**: one component set replaces about 16 to 24 prototype frames ([eeGVBhZURUI](../sources/eeGVBhZURUI.md), [0:15](https://www.youtube.com/watch?v=eeGVBhZURUI&t=15s)).
  - **Smart Animate**, which tweens layers with the same names between frames, with Bezier or spring curves ([thplNeqE9Tg](../sources/thplNeqE9Tg.md), [3:55](https://www.youtube.com/watch?v=thplNeqE9Tg&t=235s), [6:59](https://www.youtube.com/watch?v=thplNeqE9Tg&t=419s)).
  - **Variables** with modes for themes, languages and spacing ([XnI-WbMCDyw](../sources/XnI-WbMCDyw.md), [1:36](https://www.youtube.com/watch?v=XnI-WbMCDyw&t=96s)).
  - **Masks** through image fills or "Use as mask" ([KamNFblohHc](../sources/KamNFblohHc.md), [0:14](https://www.youtube.com/watch?v=KamNFblohHc&t=14s)), and four gradient types ([BASF9O2_AFo](../sources/BASF9O2_AFo.md), [0:00](https://www.youtube.com/watch?v=BASF9O2_AFo&t=0s)).
  - **Sticky scroll** and overflow settings for scroll prototypes ([s_GRc42EjNU](../sources/s_GRc42EjNU.md), [0:15](https://www.youtube.com/watch?v=s_GRc42EjNU&t=15s)).
  - **Squircle corners** as a setting ([doiaMtD80p8](../sources/doiaMtD80p8.md), [5:06](https://www.youtube.com/watch?v=doiaMtD80p8&t=306s)).

## Business model

- Freemium. Free without a team plan (2022-12) ([blDSmD5I61s](../sources/blDSmD5I61s.md), [0:50](https://www.youtube.com/watch?v=blDSmD5I61s&t=50s)).
- Some features need the paid Pro plan: video fills (2023-02) and variable modes such as dark mode or a second language (2023-06) ([NfqdWTfNYKI](../sources/NfqdWTfNYKI.md), [1:39](https://www.youtube.com/watch?v=NfqdWTfNYKI&t=99s); [XnI-WbMCDyw](../sources/XnI-WbMCDyw.md), [1:36](https://www.youtube.com/watch?v=XnI-WbMCDyw&t=96s)).

## Metrics

- No source gives Figma's revenue or user counts.
- Founders who list Figma as a cost line: [Designjoy](designjoy.md) paid $176/month for all tools, Figma included (2023-05) ([dXKzST0FE-A](../sources/dXKzST0FE-A.md), [4:52](https://www.youtube.com/watch?v=dXKzST0FE-A&t=292s)). [Skale](skale.md)'s founder says Figma is free and some peers make $30K to $40K MRR with no website (2025-10) ([YtyJ4reSQY0](../sources/YtyJ4reSQY0.md), [8:10](https://www.youtube.com/watch?v=YtyJ4reSQY0&t=490s)).

## Growth channels

- **Community and plugins.** Tim Gabe gives four reasons to start with Figma (2022-12). It is free. It was the first design tool with multiplayer mode. Its community has thousands of plugins and templates. It ships fast ([blDSmD5I61s](../sources/blDSmD5I61s.md), [0:50](https://www.youtube.com/watch?v=blDSmD5I61s&t=50s)).
- Community files give free textures, shapes and mock-ups ([NDF834BAeK0](../sources/NDF834BAeK0.md), [1:45](https://www.youtube.com/watch?v=NDF834BAeK0&t=105s); [RdHXcv1k_Dg](../sources/RdHXcv1k_Dg.md), [9:30](https://www.youtube.com/watch?v=RdHXcv1k_Dg&t=570s)). Plugins cover palettes, type scales, logos, copy checks, shadows and dark mode ([fJ36mS1NYDM](../sources/fJ36mS1NYDM.md), [0:00](https://www.youtube.com/watch?v=fJ36mS1NYDM&t=0s)).
- **Creator tutorials.** Tim Gabe's Figma and Framer tutorials took his channel past 100K subscribers (2025-01) ([dg_LmOjapRA](../sources/dg_LmOjapRA.md), [0:35](https://www.youtube.com/watch?v=dg_LmOjapRA&t=35s)). His carousel tutorial had about 286K views (2026-10) ([L-VwAxJ9hnY](../sources/L-VwAxJ9hnY.md)).

## How founders use it

- **Design before code.** [Locked](locked.md) spent 2 weeks in Figma, then built in Xcode with Claude Code ([dWeoSKLt_fc](../sources/dWeoSKLt_fc.md), [3:36](https://www.youtube.com/watch?v=dWeoSKLt_fc&t=216s)).
- **Figma screenshots as AI specs.** Tim pastes Figma screens into [Lovable](lovable.md) as visual specs ([CfwNxDEXe6I](../sources/CfwNxDEXe6I.md), [2:26](https://www.youtube.com/watch?v=CfwNxDEXe6I&t=146s)).
- **Figma to a live site.** The Framer plugin copies Figma layers into Framer. In one demo, 47 layers moved in one step ([AJBaBScKdwI](../sources/AJBaBScKdwI.md), [7:19](https://www.youtube.com/watch?v=AJBaBScKdwI&t=439s)). Clean auto layout gives a better import ([0SzJOMS0RPA](../sources/0SzJOMS0RPA.md), [2:05](https://www.youtube.com/watch?v=0SzJOMS0RPA&t=125s)). Framer beats [Webflow](webflow.md) on Figma export, which is copy and paste ([t8ThPNdc_9w](../sources/t8ThPNdc_9w.md), [1:01](https://www.youtube.com/watch?v=t8ThPNdc_9w&t=61s)).
- **Motion without After Effects.** Tim says Smart Animate replaces After Effects for most UI motion work ([nyyuyPSxqww](../sources/nyyuyPSxqww.md), [0:03](https://www.youtube.com/watch?v=nyyuyPSxqww&t=3s)).
- **Agency tool stack.** Tim's app studio uses Figma and Rive ([wmTkiF23GRQ](../sources/wmTkiF23GRQ.md), [2:27](https://www.youtube.com/watch?v=wmTkiF23GRQ&t=147s)). Skale uses Figma with Blender, After Effects and Cinema 4D ([YtyJ4reSQY0](../sources/YtyJ4reSQY0.md), [7:37](https://www.youtube.com/watch?v=YtyJ4reSQY0&t=457s)).
- **AI landing-page chain.** Relume to Figma to Figma Sites (2025-06) ([bOm9GDv96Tk](../sources/bOm9GDv96Tk.md), [0:45](https://www.youtube.com/watch?v=bOm9GDv96Tk&t=45s)).
