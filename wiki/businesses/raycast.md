Raycast is a keyboard launcher for Mac that [Tim Gabe](../people/tim-gabe.md) uses as a case study in design-led growth.

## What it is

- A launcher with a central search bar, extensions, an extension store and an API ([eWGNjTLK84c](../sources/eWGNjTLK84c.md), [6:14](https://www.youtube.com/watch?v=eWGNjTLK84c&t=374s)).
- At launch it already integrated with GitHub, Jira and Slack. Users opened assigned GitHub issues or updated Jira tickets without a browser ([eWGNjTLK84c](../sources/eWGNjTLK84c.md), [0:32](https://www.youtube.com/watch?v=eWGNjTLK84c&t=32s)).
- The target user is the Mac developer who lives on the keyboard ([eWGNjTLK84c](../sources/eWGNjTLK84c.md), [8:42](https://www.youtube.com/watch?v=eWGNjTLK84c&t=522s)).
- Tim says it did not add features on top of standard rules. It rethought how people use their computers ([bOm9GDv96Tk](../sources/bOm9GDv96Tk.md), [4:47](https://www.youtube.com/watch?v=bOm9GDv96Tk&t=287s)).

## Growth channels

- **Integrations are distribution.** A GitHub or Slack extension shows Raycast's value inside a tool the whole team uses ([eWGNjTLK84c](../sources/eWGNjTLK84c.md), [1:06](https://www.youtube.com/watch?v=eWGNjTLK84c&t=66s)). Tim: "Distribution is often just a design problem in disguise" ([eWGNjTLK84c](../sources/eWGNjTLK84c.md), [2:01](https://www.youtube.com/watch?v=eWGNjTLK84c&t=121s)).
- **Opinionated, keyboard-first UX.** Heavy mouse use feels slow on purpose. The rigid "open, type, act" model trains a habit and creates strong believers ([eWGNjTLK84c](../sources/eWGNjTLK84c.md), [3:01](https://www.youtube.com/watch?v=eWGNjTLK84c&t=181s), [4:56](https://www.youtube.com/watch?v=eWGNjTLK84c&t=296s)).
- **Loops, not features.** Each extension adds reach to the search bar. The store gives reasons to explore, and the API lets developers grow the store ([eWGNjTLK84c](../sources/eWGNjTLK84c.md), [7:14](https://www.youtube.com/watch?v=eWGNjTLK84c&t=434s)).
- **One filter for features.** Each feature must add speed, cut cognitive load or fit keyboard workflows ([eWGNjTLK84c](../sources/eWGNjTLK84c.md), [9:32](https://www.youtube.com/watch?v=eWGNjTLK84c&t=572s)).
- **Clarity over feature count.** Against Alfred, which had many options, Raycast chose a cleaner UI, better defaults and a large search bar ([eWGNjTLK84c](../sources/eWGNjTLK84c.md), [9:50](https://www.youtube.com/watch?v=eWGNjTLK84c&t=590s)).
