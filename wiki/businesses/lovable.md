Lovable is an AI app builder: you describe a web app in chat, and it writes the full-stack code. Founders in these sources use it for MVPs, landing pages and first versions, then often move off it.

## What it is

- A chat-based builder for full-stack web apps with Supabase built in. You connect a Supabase project from the Lovable UI, and Lovable writes SQL migrations you apply with one click ([CfwNxDEXe6I](../sources/CfwNxDEXe6I.md), [8:02](https://www.youtube.com/watch?v=CfwNxDEXe6I&t=482s), [9:55](https://www.youtube.com/watch?v=CfwNxDEXe6I&t=595s)).
- [Tim Gabe](../people/tim-gabe.md) built a YouTube clone with login, upload, feed, likes, comments and search in about 30 minutes without code. He says that took an engineer days or weeks a year earlier ([CfwNxDEXe6I](../sources/CfwNxDEXe6I.md), [0:00](https://www.youtube.com/watch?v=CfwNxDEXe6I&t=0s), [31:43](https://www.youtube.com/watch?v=CfwNxDEXe6I&t=1903s)).
- Sources do not name its founders.

## Business model

- Prompts cost tokens, and more tokens cost money, so users balance prompt size against usage ([CfwNxDEXe6I](../sources/CfwNxDEXe6I.md), [13:57](https://www.youtube.com/watch?v=CfwNxDEXe6I&t=837s)).
- It pays creators: Tim Gabe's tutorial (2025-02) and his tools list (2025-04) are sponsored, though he says he contacted Lovable himself ([CfwNxDEXe6I](../sources/CfwNxDEXe6I.md), [3:27](https://www.youtube.com/watch?v=CfwNxDEXe6I&t=207s), [qmJVN2158Mk](../sources/qmJVN2158Mk.md)).

## Metrics

- $1M ARR in a week and a $6B valuation, as cited by the [Shipper](shipper.md) founders (2026-05) ([Nnpz1wsTjBI](../sources/Nnpz1wsTjBI.md), [4:18](https://www.youtube.com/watch?v=Nnpz1wsTjBI&t=258s)).
- Some agencies built on Lovable make over $200K per month from internal tools for companies (2025-04) ([qmJVN2158Mk](../sources/qmJVN2158Mk.md), [1:39](https://www.youtube.com/watch?v=qmJVN2158Mk&t=99s)).

## How founders use it

- **MVP tests.** [Presh](../people/presh.md) lists Lovable, Replit or Bolt for step 3 of his playbook: ship an MVP fast ([SJOFUBNHYqU](../sources/SJOFUBNHYqU.md), [8:33](https://www.youtube.com/watch?v=SJOFUBNHYqU&t=513s), [11:37](https://www.youtube.com/watch?v=SJOFUBNHYqU&t=697s)).
- **Landing pages from research.** [Steph France](../people/steph-france.md)'s idea framework ends with a Claude prompt that writes a Lovable prompt for a landing page ([L_FY6aW9cJ4](../sources/L_FY6aW9cJ4.md), [17:54](https://www.youtube.com/watch?v=L_FY6aW9cJ4&t=1074s)).
- **App flows for designers.** Tim Gabe names Google Stitch or Lovable for app flows, and says designers who add Lovable builds can charge more ([bOm9GDv96Tk](../sources/bOm9GDv96Tk.md), [0:45](https://www.youtube.com/watch?v=bOm9GDv96Tk&t=45s), [qmJVN2158Mk](../sources/qmJVN2158Mk.md), [1:39](https://www.youtube.com/watch?v=qmJVN2158Mk&t=99s)).
- **First version, then graduate.** [Vadim Strizheus](../people/vadim-strizheus.md) built [Vugola](vugola.md) in Lovable for 4 months, then asked Claude how to leave. It pointed him to GitHub and Supabase, which cost less ([QXxESN94Y6s](../sources/QXxESN94Y6s.md), [4:19](https://www.youtube.com/watch?v=QXxESN94Y6s&t=259s)). [Lino Leighton](../people/lino-leighton.md) spent 2 months on [AbMaxx](abmaxx.md) in Lovable, threw it away and rebuilt V2 in Rork in 1 month ([RypUD_Fuaqw](../sources/RypUD_Fuaqw.md), [4:25](https://www.youtube.com/watch?v=RypUD_Fuaqw&t=265s)).

## Tips from the tutorial

- Write a requirements prompt first: overview, pages, features, database needs, visual preferences and build order. Build the UI first, then connect the database ([CfwNxDEXe6I](../sources/CfwNxDEXe6I.md), [0:59](https://www.youtube.com/watch?v=CfwNxDEXe6I&t=59s), [2:01](https://www.youtube.com/watch?v=CfwNxDEXe6I&t=121s)).
- Paste Figma screenshots as visual specs ([CfwNxDEXe6I](../sources/CfwNxDEXe6I.md), [2:26](https://www.youtube.com/watch?v=CfwNxDEXe6I&t=146s)).
- Keep each prompt small. If Lovable flags "unwanted changes", shorten the request ([CfwNxDEXe6I](../sources/CfwNxDEXe6I.md), [13:57](https://www.youtube.com/watch?v=CfwNxDEXe6I&t=837s), [16:11](https://www.youtube.com/watch?v=CfwNxDEXe6I&t=971s)).
- Paste errors it cannot see, such as DevTools console lines or a 404 ([CfwNxDEXe6I](../sources/CfwNxDEXe6I.md), [6:11](https://www.youtube.com/watch?v=CfwNxDEXe6I&t=371s), [19:14](https://www.youtube.com/watch?v=CfwNxDEXe6I&t=1154s)).
- Accept its prompts to refactor large files ([CfwNxDEXe6I](../sources/CfwNxDEXe6I.md), [18:13](https://www.youtube.com/watch?v=CfwNxDEXe6I&t=1093s)).

## Competitors and imitators

- Shipper, a smaller AI app builder that also makes mobile apps, aimed for 1% of the market Lovable and Base44 opened ([Nnpz1wsTjBI](../sources/Nnpz1wsTjBI.md), [4:18](https://www.youtube.com/watch?v=Nnpz1wsTjBI&t=258s)).
- [Josef Buettgen](../people/josef-buettgen.md) suggests a Lovable-style builder for native mobile apps as an open idea (2025-09) ([3eY71OS4MFw](../sources/3eY71OS4MFw.md), [7:41](https://www.youtube.com/watch?v=3eY71OS4MFw&t=461s)).
