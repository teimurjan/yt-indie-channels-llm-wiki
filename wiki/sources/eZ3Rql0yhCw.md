## Summary

Tim Gabe shows how to build a mesh, or aurora, gradient in Figma in three steps plus an optional fourth. He says big companies and trendy startups now use mesh gradients as a standard UI element (2022-10). The method is: draw random shapes, color them from one palette, then blur them so the colors blend. Texture, a color-dodge spot and an inner-shadow shine add depth. He prefers this manual method to a plugin, because the plugin exports a flat PNG that you cannot edit.

## Key facts

- The tutorial uses a 600 x 400 frame with "clip content" on. [0:00](https://www.youtube.com/watch?v=eZ3Rql0yhCw&t=0s)
- The core method is three or four steps: shapes, colors, blur, then optional texture, spots and shine. [0:00](https://www.youtube.com/watch?v=eZ3Rql0yhCw&t=0s)
- Noise texture: a PNG from the Figma Community, set to the "overlay" blend mode at 10% to 15% opacity. [3:06](https://www.youtube.com/watch?v=eZ3Rql0yhCw&t=186s), [4:08](https://www.youtube.com/watch?v=eZ3Rql0yhCw&t=248s)
- Spot: a rectangle with a layer blur of about 44 and the "color dodge" blend mode. [4:08](https://www.youtube.com/watch?v=eZ3Rql0yhCw&t=248s)
- The "Mesh Gradient" plugin makes gradients with handles and a randomize button, but it outputs a PNG, not vectors. [6:11](https://www.youtube.com/watch?v=eZ3Rql0yhCw&t=371s)

## Tactics

- **Step 1, shapes.** Draw circles and random pen-tool shapes in the frame. Duplicate, resize and reshape them. The shapes set the structure of the gradient. [0:00](https://www.youtube.com/watch?v=eZ3Rql0yhCw&t=0s), [1:00](https://www.youtube.com/watch?v=eZ3Rql0yhCw&t=60s)
- **Step 2, colors.** Pick one base color, copy it, and shift only the hue to get a palette. Apply the colors to the shapes. [1:00](https://www.youtube.com/watch?v=eZ3Rql0yhCw&t=60s), [2:04](https://www.youtube.com/watch?v=eZ3Rql0yhCw&t=124s)
- **Step 3, blur.** Select all shapes and add a layer blur. Raise it until the flat colors mesh together. [2:04](https://www.youtube.com/watch?v=eZ3Rql0yhCw&t=124s), [3:06](https://www.youtube.com/watch?v=eZ3Rql0yhCw&t=186s)
- **Step 4, texture.** Lay a noise PNG over everything with a subtle overlay blend. [3:06](https://www.youtube.com/watch?v=eZ3Rql0yhCw&t=186s)
- **Step 4, spots.** Add a blurred rectangle in color dodge. Change its color and blur to control how harsh it looks. [4:08](https://www.youtube.com/watch?v=eZ3Rql0yhCw&t=248s)
- **Step 4, shine.** Add a white inner shadow with a large blur from the left and bottom edges. [5:10](https://www.youtube.com/watch?v=eZ3Rql0yhCw&t=310s)
- **Keep it editable.** Build by hand to keep vector shapes that you can change later. [6:11](https://www.youtube.com/watch?v=eZ3Rql0yhCw&t=371s)
