# Parallax Scroll Animation in 6 Minutes (Figma Tutorial)

## Summary

Tim Gabe shows how to prototype a parallax scroll effect in Figma in two steps. Step one builds a start frame and an end frame. In the end frame, each layer moves by a different amount and in a different direction. Step two links the frames with a drag interaction on a fake scroll bar and Smart Animate. The working file is free in the video description.

## Key facts

- Parallax needs two or more objects that change position relative to each other in a random way while you scroll. Text, images, blurs or shapes all work. [0:30](https://www.youtube.com/watch?v=GVUchbe86HE&t=30s)
- The demo has four moving parts. A blur moves down, a text layer moves up, square images leave the frame, and round images rise into it. [0:30](https://www.youtube.com/watch?v=GVUchbe86HE&t=30s), [1:31](https://www.youtube.com/watch?v=GVUchbe86HE&t=91s)
- Frames are set to a height of 900 px so they look like desktop screens. [4:45](https://www.youtube.com/watch?v=GVUchbe86HE&t=285s)
- The transition is a drag interaction with Smart Animate and ease out. [5:45](https://www.youtube.com/watch?v=GVUchbe86HE&t=345s)

## Tactics

- **Layer order sets the look.** Put the text on top. Put the blur above the images, so it fades the images but not the text. [2:31](https://www.youtube.com/watch?v=GVUchbe86HE&t=151s)
- **Move layers by different amounts.** Elements that move together look uniform and flat. First shift each image a little. Then move the group. [1:31](https://www.youtube.com/watch?v=GVUchbe86HE&t=91s), [3:33](https://www.youtube.com/watch?v=GVUchbe86HE&t=213s)
- **Move out of view and keep the parent.** Hold Shift, then Space, while you drag. Elements leave the visible area but stay inside the frame. [3:33](https://www.youtube.com/watch?v=GVUchbe86HE&t=213s)
- **Drag a scroll bar to drive the animation.** Add a drag interaction from the scroll bar to frame two. Add a second one back to frame one. Any element can be the drag handle. A scroll bar feels more real. [4:45](https://www.youtube.com/watch?v=GVUchbe86HE&t=285s), [5:45](https://www.youtube.com/watch?v=GVUchbe86HE&t=345s)
- **Preview full screen.** Press F in presentation mode to test the scroll. [5:45](https://www.youtube.com/watch?v=GVUchbe86HE&t=345s)
