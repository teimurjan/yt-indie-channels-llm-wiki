# Get Started: Figma Variables in 3 Minutes

## Summary

Tim Gabe gives a 3-minute intro to Figma Variables. Variables let you switch color themes, copy and spacing across a design. He builds a "primitives" collection of base values, then theme and size collections that alias back to it. He adds a dark mode, a Swedish language mode, and spacing tokens. Then he applies them to a card layout to swap themes, languages and paddings from the layer panel.

## Key facts

- Open the menu: press Escape, go to the Design tab, and open Variables in the right sidebar. [0:14](https://www.youtube.com/watch?v=XnI-WbMCDyw&t=14s)
- Modes, such as a dark mode or a second language, need the Figma Pro plan (2023-06). [1:36](https://www.youtube.com/watch?v=XnI-WbMCDyw&t=96s)
- Collections group variables. Make one with "Create collection", then add values with "Create variable". [0:26](https://www.youtube.com/watch?v=XnI-WbMCDyw&t=26s), [0:31](https://www.youtube.com/watch?v=XnI-WbMCDyw&t=31s)

## Tactics

- **Start with primitives.** The first collection holds base colors and base sizes. Design system people call these primitives. Every other collection links back to them. [0:42](https://www.youtube.com/watch?v=XnI-WbMCDyw&t=42s), [0:57](https://www.youtube.com/watch?v=XnI-WbMCDyw&t=57s)
- **Theme collection with aliases.** Define semantic values like background, button, text body, primary and secondary. Each one is an alias to a primitive. [1:05](https://www.youtube.com/watch?v=XnI-WbMCDyw&t=65s), [1:18](https://www.youtube.com/watch?v=XnI-WbMCDyw&t=78s)
- **Dark mode as a mode.** Click plus on "new variable mode" and invert the values. [1:26](https://www.youtube.com/watch?v=XnI-WbMCDyw&t=86s)
- **Size collection.** Add small, medium, large and mega as aliases to primitive sizes. [1:45](https://www.youtube.com/watch?v=XnI-WbMCDyw&t=105s)
- **Copy as variables.** A languages collection holds English text, with Swedish as a second mode. These are raw strings, so no aliases. [1:59](https://www.youtube.com/watch?v=XnI-WbMCDyw&t=119s), [2:09](https://www.youtube.com/watch?v=XnI-WbMCDyw&t=129s)
- **Keep collections separate.** One combined collection works, but then you cannot switch theme, size and language on their own. [2:09](https://www.youtube.com/watch?v=XnI-WbMCDyw&t=129s), [2:21](https://www.youtube.com/watch?v=XnI-WbMCDyw&t=141s)
- **Link everything before you swap.** Link every color on the card first, or the theme switch in the Layer panel leaves gaps. [2:38](https://www.youtube.com/watch?v=XnI-WbMCDyw&t=158s), [2:50](https://www.youtube.com/watch?v=XnI-WbMCDyw&t=170s)
- **Change once, update everywhere.** Edit a color in the primitives collection and every linked layer updates. [3:04](https://www.youtube.com/watch?v=XnI-WbMCDyw&t=184s)
- **Spacing tokens.** Link padding, corner radius and gaps on a frame to the spacing collection. [3:20](https://www.youtube.com/watch?v=XnI-WbMCDyw&t=200s), [3:28](https://www.youtube.com/watch?v=XnI-WbMCDyw&t=208s)
