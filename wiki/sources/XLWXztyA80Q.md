# From Figma to Framer (Get Started in 28 Minutes)

## Summary

Tim Gabe walks Figma users through the Framer editor panel by panel. He uses the "Boost" template as the example. He maps each Framer feature to its Figma counterpart: rows and columns are auto layout ("stacks"), frames and text work the same way, and the layers panel is almost identical. Then he points out what only Framer has: pages are live URLs, text styles have built-in breakpoints, link states, CMS, overlays, scroll effects, real CSS sizing units, and one-click publishing. The goal is to give designers enough confidence to build responsive sites in Framer.

## Key facts

- The video dates from 2022-12, so the Framer UI it shows may have changed since.
- New projects start blank or from templates such as "Starter" and "Boost". Templates come with desktop, tablet and phone frames [1:02](https://www.youtube.com/watch?v=XLWXztyA80Q&t=62s).
- The Insert panel holds ready-made sections (navbars, footers, collection lists), embeds (Spotify, SoundCloud, Formspark, HubSpot, Intercom, Gumroad, Eventbrite, YouTube, Vimeo, Lottie, GIFs), icon libraries, and Framer components (carousel, ticker, slideshow). Figma has nothing like this natively [2:20](https://www.youtube.com/watch?v=XLWXztyA80Q&t=140s), [3:20](https://www.youtube.com/watch?v=XLWXztyA80Q&t=200s).
- Layout presets: rows (vertical auto layout), columns (horizontal auto layout), wrap, and grids [4:23](https://www.youtube.com/watch?v=XLWXztyA80Q&t=263s).
- Pages are real website pages with URLs. A separate "canvas" page is a design playground that does not publish [6:38](https://www.youtube.com/watch?v=XLWXztyA80Q&t=398s).
- Site settings: SEO title and description, social preview image, password protection, Google Analytics, custom code, domains, redirects, versions, and built-in analytics [13:29](https://www.youtube.com/watch?v=XLWXztyA80Q&t=809s).
- Publish deploys to a random Framer domain, which you can change to a custom domain [15:34](https://www.youtube.com/watch?v=XLWXztyA80Q&t=934s).

## Tactics

- **Start from a template** that looks close to what you want, so you do not start from scratch [1:02](https://www.youtube.com/watch?v=XLWXztyA80Q&t=62s).
- **Use responsive text styles.** Each Framer text style has L, M and S sizes for breakpoints. You can remove or add breakpoints per style [10:44](https://www.youtube.com/watch?v=XLWXztyA80Q&t=644s).
- **Style link states without components.** Link styles have default, hover and current states built in. In Figma you would need component variants [11:44](https://www.youtube.com/watch?v=XLWXztyA80Q&t=704s).
- **Drop to code when the UI is not enough.** Code components (.tsx) add custom behavior or external libraries. Code overrides change existing canvas elements [12:46](https://www.youtube.com/watch?v=XLWXztyA80Q&t=766s), [26:21](https://www.youtube.com/watch?v=XLWXztyA80Q&t=1581s).
- **Use web sizing units.** Besides fixed, fill and fit, Framer offers relative sizes, viewport height (100vh), and min/max width and height [19:10](https://www.youtube.com/watch?v=XLWXztyA80Q&t=1150s), [20:10](https://www.youtube.com/watch?v=XLWXztyA80Q&t=1210s).
- **Add motion with effects.** Scroll speed (parallax), scroll transform, scroll variants, and appear animations triggered when a layer enters the view [22:14](https://www.youtube.com/watch?v=XLWXztyA80Q&t=1334s).
- **One "realistic" shadow** replaces stacking several Figma shadows [24:18](https://www.youtube.com/watch?v=XLWXztyA80Q&t=1458s).
- **Scroll sections and offsets.** Name a section, link a button to it, and add a pixel offset for a sticky navbar [25:20](https://www.youtube.com/watch?v=XLWXztyA80Q&t=1520s).
- **Set accessibility and semantics.** Add an ARIA label, tab order, and H1/H2 tags per element [25:20](https://www.youtube.com/watch?v=XLWXztyA80Q&t=1520s), [26:21](https://www.youtube.com/watch?v=XLWXztyA80Q&t=1581s).
- **Hand off code.** The handoff panel shows CSS or JSX to copy, like Figma's inspect tab [27:22](https://www.youtube.com/watch?v=XLWXztyA80Q&t=1642s).
