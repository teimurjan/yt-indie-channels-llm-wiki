# How I Built It: $17K/Month Open Source SaaS

## Summary

Pat Walls interviews Nevo, who builds Postiz, an open-source social media scheduler for 25 platforms. Postiz makes $17K MRR in a crowded market. Nevo says open source is the differentiator: developers will not pay, but they build the brand, spread word of mouth, write SEO content and report bugs. The paid cloud product is the same as the open-source code. Nevo shares a five-step launch playbook to reach GitHub trending in one week.

## Key facts

- $17K MRR from 472 subscribers (2026-01) ([2:25](https://www.youtube.com/watch?v=RPM4ImzcIFc&t=145s)).
- Monthly churn is 19%, which he calls very high (2026-01) ([2:25](https://www.youtube.com/watch?v=RPM4ImzcIFc&t=145s)).
- 3,830 trials since August 2025, with 21% trial to paid conversion (2026-01) ([2:25](https://www.youtube.com/watch?v=RPM4ImzcIFc&t=145s)).
- Over 25K GitHub stars and 5M downloads (2026-01) ([0:14](https://www.youtube.com/watch?v=RPM4ImzcIFc&t=14s)).
- Tiers: Standard, Team, Pro and Ultimate. Tiers differ by channel count and features ([2:25](https://www.youtube.com/watch?v=RPM4ImzcIFc&t=145s)).
- Before Postiz, he worked 2 years at an open-source notification startup that grew from 0 to 32,000 stars. He then did open-source consulting for about a year ([4:06](https://www.youtube.com/watch?v=RPM4ImzcIFc&t=246s)).
- Margin is about 80%. The video conversion tool costs $600 per month. AI image and text generation is the biggest cost (2026-01) ([19:15](https://www.youtube.com/watch?v=RPM4ImzcIFc&t=1155s), [20:16](https://www.youtube.com/watch?v=RPM4ImzcIFc&t=1216s)).

## Tactics

- **Open source as a differentiator.** AI lets anyone build anything, so code has little value and brand wins. Open source gets a project in front of millions of developers ([6:46](https://www.youtube.com/watch?v=RPM4ImzcIFc&t=406s)).
- **Treat self-hosting as a free tier.** Developers rarely pay. They bring word of mouth inside their companies, UGC, bug reports, blog posts and directory listings with high domain authority ([7:34](https://www.youtube.com/watch?v=RPM4ImzcIFc&t=454s), [8:35](https://www.youtube.com/watch?v=RPM4ImzcIFc&t=515s)).
- **Enterprise money.** The biggest open-source revenue is self-hosted enterprise support ([8:35](https://www.youtube.com/watch?v=RPM4ImzcIFc&t=515s)).
- **Copies fail.** People copied Postiz and hosted it as rivals. They gave up within weeks, because the creator owns the brand ([9:37](https://www.youtube.com/watch?v=RPM4ImzcIFc&t=577s)).
- **Step 1, prepare the repo** ([10:35](https://www.youtube.com/watch?v=RPM4ImzcIFc&t=635s), [11:36](https://www.youtube.com/watch?v=RPM4ImzcIFc&t=696s)):
  - Treat the GitHub README as your landing page. Call it "an open-source alternative to X" for fast context.
  - Pick a license: MIT, Apache 2 or AGPL 3.
  - Open issues for features you want built, so contributors can claim them.
  - Open a Discord. Write deploy docs and ship a Docker image, or developers churn.
- **Step 2, write articles.** Create Hacker News and Reddit accounts 2 weeks early and build Reddit karma. Post on dev.to, Medium and Hackernoon. Google Discover is their main traffic source, so invest in titles and cover images ([12:37](https://www.youtube.com/watch?v=RPM4ImzcIFc&t=757s), [13:38](https://www.youtube.com/watch?v=RPM4ImzcIFc&t=818s)).
- **Lemmy.** This self-hosted Reddit alternative is strong for open source. His posts get at least 100 upvotes there ([12:37](https://www.youtube.com/watch?v=RPM4ImzcIFc&t=757s)).
- **Step 3, Show HN.** Link to the GitHub repo, not the website. A front-page post brings about 10,000 views ([13:38](https://www.youtube.com/watch?v=RPM4ImzcIFc&t=818s)).
- **Step 4, r/selfhosted.** Open-source projects can self-promote there. Repost each new version every month. Use "I", not "we", stay humble, and ask for a star. Also try r/webdev, r/programming and AI subreddits ([14:32](https://www.youtube.com/watch?v=RPM4ImzcIFc&t=872s)).
- **Step 5, push all other traffic.** Send X, LinkedIn and newsletter traffic to GitHub. Run all five steps in the same week to hit GitHub trending ([15:34](https://www.youtube.com/watch?v=RPM4ImzcIFc&t=934s)).
- **Public API.** Developers prefer an open-source tool they can automate with n8n or the API ([18:22](https://www.youtube.com/watch?v=RPM4ImzcIFc&t=1102s)).
- **Stack.** Railway for hosting and Vercel for Next.js. Semrush and Ahrefs ($20 dashboard) for SEO. Resend, Cloudflare R2 and Plausible. Dub.co for short links and affiliates. OpenAI and fal for AI media. Outrank writes one SEO article per day. Cursor ($20), WebStorm and Beehiiv. Discord support, Copilot, Sentry and GitHub Actions are free for open source ([19:15](https://www.youtube.com/watch?v=RPM4ImzcIFc&t=1155s), [20:16](https://www.youtube.com/watch?v=RPM4ImzcIFc&t=1216s)).
- **Learn before you build.** He read Traction, Alex Hormozi's $100M Offers and Russell Brunson after many failures. Split time half learning, half building. B2C is harder for founders weak at distribution ([20:54](https://www.youtube.com/watch?v=RPM4ImzcIFc&t=1254s)).
