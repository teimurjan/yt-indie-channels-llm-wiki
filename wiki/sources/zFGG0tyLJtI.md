# 15 Figma Shortcuts You Need to Know About

## Summary

Tim Gabe shows 15 Figma keyboard shortcuts in about 6 minutes. They cover resizing, alignment and zoom, layers, copy and paste, and a few extras. He cites Brainscape: shortcuts save about eight days a year. The video is a quick reference for designers who want to work faster in Figma. Keys below are for Mac. On Windows, Option is Alt and Command is Ctrl.

## Key facts

- Brainscape says keyboard shortcuts save an average of eight days a year. [0:00](https://www.youtube.com/watch?v=zFGG0tyLJtI&t=0s)
- The video has five groups: resizing, alignment and zoom, layers, copy and paste, and bonus shortcuts. [0:29](https://www.youtube.com/watch?v=zFGG0tyLJtI&t=29s)

## Tactics

Resizing:

- **Scale everything: K.** Press K, then drag. The frame and all content inside it scale together. Shift only resizes the outer frame. [0:41](https://www.youtube.com/watch?v=zFGG0tyLJtI&t=41s)
- **Resize from the center: Shift + Option.** All sides move at the same time, and the element stays centered. Without it, the element follows its constraint settings. [1:08](https://www.youtube.com/watch?v=zFGG0tyLJtI&t=68s)

Alignment and zoom:

- **Align two or more elements: Option + A, D, S or W.** These keys align to the left, right, bottom or top. [1:37](https://www.youtube.com/watch?v=zFGG0tyLJtI&t=97s)
- **Center in the parent frame: Option + V or Option + H.** V centers vertically. H centers horizontally. [2:01](https://www.youtube.com/watch?v=zFGG0tyLJtI&t=121s)
- **Zoom to the selected frame: Shift + 2.** [2:22](https://www.youtube.com/watch?v=zFGG0tyLJtI&t=142s)
- **Zoom out to the full canvas: Shift + 1.** [2:37](https://www.youtube.com/watch?v=zFGG0tyLJtI&t=157s)

Layers:

- **Copy and paste a layer style: Option + Command + C, then Option + Command + V.** Tim calls it a game changer. [2:48](https://www.youtube.com/watch?v=zFGG0tyLJtI&t=168s)
- **Swap fill and stroke: Shift + X.** [3:13](https://www.youtube.com/watch?v=zFGG0tyLJtI&t=193s)
- **Select the deepest layer: hold Command (Ctrl on Windows) and hover.** This targets an avatar inside an auto layout, not the whole auto layout. [3:29](https://www.youtube.com/watch?v=zFGG0tyLJtI&t=209s)
- **Keep a layer out of auto layout: hold Space while you drag.** Figma then does not drop the layer into the nearest auto layout. [3:45](https://www.youtube.com/watch?v=zFGG0tyLJtI&t=225s)

Copy and paste:

- **Duplicate in a sequence: Command + D.** After one duplicate, each new copy keeps the same distance from the one before. [4:13](https://www.youtube.com/watch?v=zFGG0tyLJtI&t=253s)
- **Copy as PNG: Shift + Command + C.** Paste it as an image anywhere. [4:31](https://www.youtube.com/watch?v=zFGG0tyLJtI&t=271s)

Bonus:

- **Quick menu: Command + P or Command + /.** Search menus, commands and plugins. [4:58](https://www.youtube.com/watch?v=zFGG0tyLJtI&t=298s)
- **Hide the Figma UI: Command + \\.** Tim uses it in his tutorials. [5:10](https://www.youtube.com/watch?v=zFGG0tyLJtI&t=310s)
- **Rename in bulk: Command + R.** Select many frames and give them one name, for example "Card". [5:25](https://www.youtube.com/watch?v=zFGG0tyLJtI&t=325s)
