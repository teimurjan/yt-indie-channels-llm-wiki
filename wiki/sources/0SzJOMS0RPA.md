## Summary

Tim Gabe shows how to turn a Figma design into a live, responsive website with Framer Sites. He copies a Figma frame with the Framer plugin, pastes it into Framer, fixes fonts and sizing, adds breakpoints and publishes. He also builds a button component with a hover state. He says he is not paid by Framer. His view: Framer can become one app where designers design, publish and edit content in a CMS.

## Key facts

- Framer Sites was free at the time and imports Figma designs straight onto its canvas (2022-09) [0:00](https://www.youtube.com/watch?v=0SzJOMS0RPA&t=0s).
- Tim says he is not affiliated with Framer [1:03](https://www.youtube.com/watch?v=0SzJOMS0RPA&t=63s).
- The demo frame was 1440 px wide. The font was Satoshi Bold, which he had to set again after import [1:03](https://www.youtube.com/watch?v=0SzJOMS0RPA&t=63s).
- Framer design tools were less flexible than Figma at the time (2022-09) [0:00](https://www.youtube.com/watch?v=0SzJOMS0RPA&t=0s).

## Tactics

- **Import flow.** Select the frame in Figma and run the Framer plugin, which copies the layers. Paste into a wider Framer canvas [1:03](https://www.youtube.com/watch?v=0SzJOMS0RPA&t=63s).
- **Set up Figma well first.** Clean auto layout makes a better import, because it matches how a real website is built [2:05](https://www.youtube.com/watch?v=0SzJOMS0RPA&t=125s).
- **Fix after import.** Set fonts again. Unlock aspect ratios. Change fixed-width text to "fill" so it resizes [2:05](https://www.youtube.com/watch?v=0SzJOMS0RPA&t=125s), [3:07](https://www.youtube.com/watch?v=0SzJOMS0RPA&t=187s).
- **Breakpoints.** Add tablet and phone breakpoints. On phone, cut the font to about 72, stack the auto layout vertically, align left and set a gap. Give the container 16 px side margins [3:07](https://www.youtube.com/watch?v=0SzJOMS0RPA&t=187s), [4:09](https://www.youtube.com/watch?v=0SzJOMS0RPA&t=249s).
- **Components.** Press Option+Command+K to make a component, then add a hover state with padding, radius, color and shadow changes. Framer can hold a full design system: text styles, buttons and inputs [5:10](https://www.youtube.com/watch?v=0SzJOMS0RPA&t=310s).
