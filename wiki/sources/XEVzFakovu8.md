## Summary

Tim Gabe shows three beta updates to Figma component properties from September 2022. "Simplify all instances" hides options that do not matter for a component. "Nested instances" shows a child component's properties on the parent, such as a button inside a card. "Preferred values" limits instance swaps to a short list, for example a few icons, so you do not scroll a huge icon library. The video is a short, step-by-step tutorial for people who build design systems in Figma.

## Key facts

- At release (2022-09), these features were in beta. You turn them on per component: select the component, open the component configuration icon in the right panel, and enable the beta. [0:29](https://www.youtube.com/watch?v=XEVzFakovu8&t=29s)
- "Simplify all instances" is checked by default in that panel. It slims down the right panel for instances of that component. [0:54](https://www.youtube.com/watch?v=XEVzFakovu8&t=54s)
- Nested instances: on the main component, click the plus in Properties and choose "Nested instances". Then check which child components show on the parent. [1:46](https://www.youtube.com/watch?v=XEVzFakovu8&t=106s)
- Preferred values: on the main component, hover the icon property, click edit property, and add preferred values. [3:21](https://www.youtube.com/watch?v=XEVzFakovu8&t=201s)

## Tactics

- **Hide what designers do not need.** Use "Simplify all instances" so each instance shows only the options that matter. Compare a simplified and a non-simplified card to see the difference. [0:54](https://www.youtube.com/watch?v=XEVzFakovu8&t=54s)
- **Expose nested components on the parent.** Check the button under nested instances. Designers can then change the card's button from the card itself, without digging through layers. This helps most with deep components. [1:46](https://www.youtube.com/watch?v=XEVzFakovu8&t=106s), [2:34](https://www.youtube.com/watch?v=XEVzFakovu8&t=154s)
- **Curate instance swaps.** Add only the right icons, such as an arrow, as preferred values on a button. The swap menu then shows those first. [2:34](https://www.youtube.com/watch?v=XEVzFakovu8&t=154s), [3:21](https://www.youtube.com/watch?v=XEVzFakovu8&t=201s)
