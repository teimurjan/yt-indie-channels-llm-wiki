# Make Your Figma Scroll Animation Real in 4 Minutes (Using Framer)

## Summary

Tim Gabe shows how to turn a Figma parallax prototype into a live website animation in Framer. A Figma prototype is not a product that a client or user can use. A Framer site is. The process has two steps: copy the Figma frame into Framer with the Framer plugin, then set a different scroll speed for each layer. The video is a short tutorial with no business metrics. The working file is linked as a Framer remix.

## Key facts

- The tool chain is Figma for the design and Framer for the live site. The Figma "Framer" plugin copies the layers [0:30](https://www.youtube.com/watch?v=7drmXMS8Jj8&t=30s).
- In Framer, scroll speed 100 equals normal scrolling. Values above 100 move a layer faster than the page, and values below 100 move it slower [1:22](https://www.youtube.com/watch?v=7drmXMS8Jj8&t=82s).
- Example settings: 140 for the images, 250 for the background blur ("shimmer") layer and 40 to 50 for the parallax text [1:22](https://www.youtube.com/watch?v=7drmXMS8Jj8&t=82s), [2:24](https://www.youtube.com/watch?v=7drmXMS8Jj8&t=144s).
- The tutorial takes about 4 minutes from Figma frame to a page that is ready to publish [3:27](https://www.youtube.com/watch?v=7drmXMS8Jj8&t=207s).

## Tactics

- **Step 1: gather the assets.** In Figma, select the desktop frame. Open Resources, then Plugins, and run the Framer plugin to copy the layers. Paste them into Framer with Cmd+V or Ctrl+V [0:30](https://www.youtube.com/watch?v=7drmXMS8Jj8&t=30s).
- **Step 2: size the frame.** Set the outer frame's width to match the Figma export and its height to "fit content". Press Cmd+P to preview. The site can now be published, but it is static [1:22](https://www.youtube.com/watch?v=7drmXMS8Jj8&t=82s).
- **Step 3: add scroll speed.** Select the images, open the Effects panel and set the scroll speed above 100 so they move up faster than the scroll. Give the background blur a higher value and the text a lower value to get depth [1:22](https://www.youtube.com/watch?v=7drmXMS8Jj8&t=82s), [2:24](https://www.youtube.com/watch?v=7drmXMS8Jj8&t=144s).
- **Make it more dynamic.** Give each image its own scroll speed [2:24](https://www.youtube.com/watch?v=7drmXMS8Jj8&t=144s).
- **Why ship in Framer.** A live project lets clients and users use the design, which a prototype cannot do [0:00](https://www.youtube.com/watch?v=7drmXMS8Jj8&t=0s).
