# 9 SECRETS To Beautiful Landing Page Design (Pt. 2: Guiding Principles)

## Summary

Part 2 of Tim Gabe's landing-page series sets the base rules before any design work in Figma. He groups them as text, color and structural principles. Text: use one font, set a type scale early, tune line height, weight and letter spacing, and keep body text legible. Color: save strong colors for calls to action, use subtle tints and shades, and check contrast against WCAG AA. Structure: an 8-point grid, a baseline grid and a 12-column layout.

## Key facts

- One font is enough, for beginners and for seasoned designers. [0:33](https://www.youtube.com/watch?v=cmSBbnrFGPg&t=33s)
- The Type Scales plugin builds a text hierarchy from a base size, such as 18px, and a ratio, such as 1.25 or 1.3. It can round the values. [1:35](https://www.youtube.com/watch?v=cmSBbnrFGPg&t=95s), [2:35](https://www.youtube.com/watch?v=cmSBbnrFGPg&t=155s)
- Medium uses a 20px base size for article text. 12px is not legible for long paragraphs. [4:37](https://www.youtube.com/watch?v=cmSBbnrFGPg&t=277s)
- The Contrast plugin shows AA and AAA pass or fail for normal text, large text and graphics. [8:31](https://www.youtube.com/watch?v=cmSBbnrFGPg&t=511s)
- Button sizes on the 8-point grid: large is 64px high with 32px horizontal padding. Medium is 48px with 24px. Small is 40px with 16px. [10:26](https://www.youtube.com/watch?v=cmSBbnrFGPg&t=626s)
- His 12-column layout uses a 156px margin and a 20px gutter. [12:27](https://www.youtube.com/watch?v=cmSBbnrFGPg&t=747s)

## Tactics

- **Set the type scale first.** It tells you which text sizes you will use. Make it by hand or with the Type Scales plugin. [1:35](https://www.youtube.com/watch?v=cmSBbnrFGPg&t=95s)
- **Copy text settings from references.** The same font (Inter) can look balanced or broken, depending on line height, weight and letter spacing. Find a similar font in your reference designs and copy its settings. [3:35](https://www.youtube.com/watch?v=cmSBbnrFGPg&t=215s)
- **Design for reading.** Award-winning sites often use text that is hard to read. For content-heavy pages, such as blogs, legibility comes first. [4:37](https://www.youtube.com/watch?v=cmSBbnrFGPg&t=277s)
- **Strong color only for what matters.** Give the primary color to the main CTA, such as "join the waiting list." Google keeps the page white and gray, so its blue button stands out. [5:27](https://www.youtube.com/watch?v=cmSBbnrFGPg&t=327s), [6:28](https://www.youtube.com/watch?v=cmSBbnrFGPg&t=388s)
- **Use tints and shades.** Copy.ai lowers the opacity of its primary color for the footer background. Gray cards on white work in light mode and in dark mode. [6:28](https://www.youtube.com/watch?v=cmSBbnrFGPg&t=388s), [7:29](https://www.youtube.com/watch?v=cmSBbnrFGPg&t=449s)
- **Check contrast.** Body text must pass at least the AA standard. [8:31](https://www.youtube.com/watch?v=cmSBbnrFGPg&t=511s)
- **Use the 8-point grid.** Make padding, gaps, icon sizes and button heights divisible by 8, for example 56, 40, 24, 96 and 64. Developers then know the pattern. [9:40](https://www.youtube.com/watch?v=cmSBbnrFGPg&t=580s), [10:26](https://www.youtube.com/watch?v=cmSBbnrFGPg&t=626s)
- **Add a baseline grid.** Add a row layout grid with about 1,000 rows, top alignment, 8px height and 8px gutter. Objects snap to 8px. You can hide the red lines and keep the snap. [11:27](https://www.youtube.com/watch?v=cmSBbnrFGPg&t=687s)
- **Use a 12-column layout.** It is how developers build for the web. Fit every wireframe section to it. [12:27](https://www.youtube.com/watch?v=cmSBbnrFGPg&t=747s), [13:28](https://www.youtube.com/watch?v=cmSBbnrFGPg&t=808s)
