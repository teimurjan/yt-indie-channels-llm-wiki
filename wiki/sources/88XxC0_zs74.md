# 6 UI Hacks I Wish I Knew As A Beginner

## Summary

Tim Gabe gives six practical rules for text and spacing in UI layouts. He applies each one to a sample layout to show the before and after. The rules cover line height, letter spacing, text alignment, line length, hierarchy with few font sizes, and spacing based on how closely elements relate. He says typography is a core design skill that he ignored in design school. It is about how you use a font, not which font you choose.

## Key facts

- Heading line height on big sites: Google and Dropbox use about 1.2x the text size. Uber uses about 1.2x to 1.5x. Body text on the same sites is about 1.4x to 1.5x. [2:12](https://www.youtube.com/watch?v=88XxC0_zs74&t=132s)
- Larger text needs a smaller line-height ratio. [2:12](https://www.youtube.com/watch?v=88XxC0_zs74&t=132s)
- The Baymard Institute found that long lines of text intimidate users. Users then skip the text, miss the benefits and convert less. [6:15](https://www.youtube.com/watch?v=88XxC0_zs74&t=375s)
- Baymard recommends 50 to 75 characters per line for body text. At about 18px, that is about 600px wide on desktop. [7:17](https://www.youtube.com/watch?v=88XxC0_zs74&t=437s)

## Tactics

1. **Line height.** Use 1.1x to 1.3x the size for headings and 1.3x to 1.5x for body text. [3:14](https://www.youtube.com/watch?v=88XxC0_zs74&t=194s)
2. **Letter spacing.** Crisp headings use negative letter spacing, about -1% to -2%. Keep body text at default, because tight spacing hurts readability. The right value depends on the font, and less is safer. [3:37](https://www.youtube.com/watch?v=88XxC0_zs74&t=217s), [4:39](https://www.youtube.com/watch?v=88XxC0_zs74&t=279s)
3. **Alignment.** Center alignment slows reading, because the eye must find the start of each line. Left-align any text longer than three lines. Never mix a centered heading with left-aligned body text. [5:01](https://www.youtube.com/watch?v=88XxC0_zs74&t=301s), [6:01](https://www.youtube.com/watch?v=88XxC0_zs74&t=361s)
4. **Line length.** Keep body text at 50 to 75 characters, about 600px on desktop. [7:17](https://www.youtube.com/watch?v=88XxC0_zs74&t=437s)
5. **Hierarchy.** Too many font sizes look messy. Try to use only two sizes, and show hierarchy with weight and subtle color changes. [7:56](https://www.youtube.com/watch?v=88XxC0_zs74&t=476s)
6. **Spacing by relationship.** Put closely related elements closer together. A heading sits 1x (16px) from its own body text and 2x (32px) from the text above it. Use the same rule for CTAs and hero text, and for logos and nav links. [8:38](https://www.youtube.com/watch?v=88XxC0_zs74&t=518s), [9:39](https://www.youtube.com/watch?v=88XxC0_zs74&t=579s)

## Quotes
