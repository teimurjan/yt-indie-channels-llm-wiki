# The 8 Most Underrated Figma Plugins in 2022

## Summary

Tim Gabe demos eight Figma plugins that he says few designers talk about. They cover color palettes, color shades, type scales, brand logos, copy checks, shadows, combined layer styles and dark mode. He uses them together to build one small card design. The point is to skip setup work at the start of a project, such as building text styles or a dark mode version by hand.

## Key facts

- The eight plugins: Coolors, Color Shades, Typescales, Vector Logos, Writer for Figma, Beautiful Shadows, Layer Styles and Dark Mode Magic (2022-06). [0:00](https://www.youtube.com/watch?v=fJ36mS1NYDM&t=0s)
- The Coolors plugin has Generate, Library and Explore tabs. Library needs a free Coolors account. [0:32](https://www.youtube.com/watch?v=fJ36mS1NYDM&t=32s)
- Typescales example settings: base size 16, scale ratio about 1.3 to 1.5, line height 1.3, 6 steps down and 2 steps up, with rounded values. It also outputs rem values. [2:58](https://www.youtube.com/watch?v=fJ36mS1NYDM&t=178s), [3:58](https://www.youtube.com/watch?v=fJ36mS1NYDM&t=238s)
- Writer for Figma scores text on spelling, grammar, terms, style, clarity, delivery and inclusivity. [6:22](https://www.youtube.com/watch?v=fJ36mS1NYDM&t=382s)

## Tactics

- **Lock colors as you generate.** In Coolors, lock the colors you like and regenerate the rest. Then add the palette to the document as color styles. [0:32](https://www.youtube.com/watch?v=fJ36mS1NYDM&t=32s), [1:32](https://www.youtube.com/watch?v=fJ36mS1NYDM&t=92s)
- **Build a full shade range from one color.** Paste one hex code into Color Shades to get its shades and tints. [2:16](https://www.youtube.com/watch?v=fJ36mS1NYDM&t=136s)
- **Generate the type scale, then edit.** Typescales makes the base text hierarchy. Change the weights, then save each one as a text style. [2:58](https://www.youtube.com/watch?v=fJ36mS1NYDM&t=178s), [3:58](https://www.youtube.com/watch?v=fJ36mS1NYDM&t=238s)
- **Give developers rem values.** Rem sizes keep type the same across devices. [3:58](https://www.youtube.com/watch?v=fJ36mS1NYDM&t=238s)
- **Get brand logos as vectors.** Vector Logos has many company logos, for example Spotify, in several versions. [4:55](https://www.youtube.com/watch?v=fJ36mS1NYDM&t=295s)
- **Move a light source to set shadows.** Beautiful Shadows shows the result live. Tim uses it for Apple-style mockup effects. [7:23](https://www.youtube.com/watch?v=fJ36mS1NYDM&t=443s)
- **Save combined styles.** Figma saves color and text styles. Layer Styles also saves radius, stroke, shadow and fill as one style, for example "32px border radius + big shadow". [8:15](https://www.youtube.com/watch?v=fJ36mS1NYDM&t=495s)
- **Convert to dark mode in one step.** Select a frame, or only the auto layout inside it, and run Dark Mode Magic. [9:22](https://www.youtube.com/watch?v=fJ36mS1NYDM&t=562s), [10:24](https://www.youtube.com/watch?v=fJ36mS1NYDM&t=624s)
