## Summary

Tim Gabe builds a responsive, animated marketing website in Framer from scratch in about 30 minutes. He calls Framer the fastest and most flexible web design tool on the market (2023-05). The workflow has four parts: a style guide, a skeleton made from Framer's pre-made sections, design tweaks with stacks, then tablet and phone breakpoints. He ends with appear animations, scroll-triggered card effects and parallax.

## Key facts

- The style guide page holds three groups. Color styles: teal, white, blue. Text styles: heading 1, heading 2, body large, medium and small. Components with desktop and mobile variants: the logo, and buttons with hover states. [0:35](https://www.youtube.com/watch?v=PYskozIWh-E&t=35s), [1:35](https://www.youtube.com/watch?v=PYskozIWh-E&t=95s), [2:36](https://www.youtube.com/watch?v=PYskozIWh-E&t=156s)
- Layout values used: 56 px side padding and gaps on desktop, 40 px on tablet, 24 px on mobile. Max width is 1440 px. Cards use 56 px radius, 48 px gap, 40 px padding and 700 px height. [8:08](https://www.youtube.com/watch?v=PYskozIWh-E&t=488s), [13:14](https://www.youtube.com/watch?v=PYskozIWh-E&t=794s), [14:15](https://www.youtube.com/watch?v=PYskozIWh-E&t=855s)
- A Figma-to-Framer plugin can port a finished design over, but he builds step by step to teach the tool. [3:37](https://www.youtube.com/watch?v=PYskozIWh-E&t=217s)

## Tactics

- **Start with a style guide.** Shared color and text styles change everywhere at once. This scales for bigger sites. [0:35](https://www.youtube.com/watch?v=PYskozIWh-E&t=35s), [2:36](https://www.youtube.com/watch?v=PYskozIWh-E&t=156s)
- **Place the reference design on the canvas.** Paste the Figma design next to the page and match it. [3:37](https://www.youtube.com/watch?v=PYskozIWh-E&t=217s), [4:30](https://www.youtube.com/watch?v=PYskozIWh-E&t=270s)
- **Use pre-made sections for the skeleton.** Insert nav bar, hero with video, two-card layout, CTA header and footer. These sections bring responsive behavior and padding for free. [4:30](https://www.youtube.com/watch?v=PYskozIWh-E&t=270s), [5:31](https://www.youtube.com/watch?v=PYskozIWh-E&t=331s), [6:32](https://www.youtube.com/watch?v=PYskozIWh-E&t=392s)
- **Stacks are auto layout.** Framer stacks work like Figma auto layout or CSS flexbox. Set distribution to end and alignment to left to pin hero text to the bottom left. [9:10](https://www.youtube.com/watch?v=PYskozIWh-E&t=550s)
- **Video hero.** Add a video, set it to absolute position with 0 on all sides, and send it back with z-index 0. Set the hero height to 100vh. Add a blue overlay with the "color" blend mode. [10:12](https://www.youtube.com/watch?v=PYskozIWh-E&t=612s), [11:12](https://www.youtube.com/watch?v=PYskozIWh-E&t=672s), [12:14](https://www.youtube.com/watch?v=PYskozIWh-E&t=734s)
- **Floating images.** Set images inside a stack to absolute so they float freely. [17:20](https://www.youtube.com/watch?v=PYskozIWh-E&t=1040s)
- **Breakpoints.** Add tablet and phone views. Switch card direction from horizontal to vertical, lower padding, and swap component variants to mobile. Framer gives a hamburger menu open state for free. [20:07](https://www.youtube.com/watch?v=PYskozIWh-E&t=1207s), [21:08](https://www.youtube.com/watch?v=PYskozIWh-E&t=1268s), [22:08](https://www.youtube.com/watch?v=PYskozIWh-E&t=1328s)
- **Animations:** [26:31](https://www.youtube.com/watch?v=PYskozIWh-E&t=1591s), [27:31](https://www.youtube.com/watch?v=PYskozIWh-E&t=1651s), [28:34](https://www.youtube.com/watch?v=PYskozIWh-E&t=1714s), [29:37](https://www.youtube.com/watch?v=PYskozIWh-E&t=1777s), [30:24](https://www.youtube.com/watch?v=PYskozIWh-E&t=1824s)
  - Appear effect on text: slide in from the left with a spring. Stagger the second line with a 0.5 s delay.
  - Cards: scale from 0.8, rotate 10 degrees on the y-axis, offset 25 px. Trigger them "in view" with the viewport aligned to the middle.
  - Parallax: set scroll speed to about 110 to 140 and set section overflow to visible.
