## Summary

Tim Gabe gives a 20-minute beginner tour of Figma. He rebuilds the hero section of the website for Anchor, a Spotify podcast company, from a screenshot. He covers the main panels, the toolbar, frames and text. He also shows plugins, auto layout, shapes, the pen tool, image crops and selection colors. He argues that Figma is the right first tool because it is free, collaborative, community-driven and fast to ship.

## Key facts

- Four reasons for Figma (2022-12). It is free without a team plan. It was the first design tool with multiplayer mode. Its community has thousands of plugins and templates. It ships features fast. [0:50](https://www.youtube.com/watch?v=blDSmD5I61s&t=50s)
- Figma runs as a desktop app or in the browser. [1:38](https://www.youtube.com/watch?v=blDSmD5I61s&t=98s)
- Interface: layers, assets and pages on the left, element settings on the right, tools on top. [2:23](https://www.youtube.com/watch?v=blDSmD5I61s&t=143s), [3:06](https://www.youtube.com/watch?v=blDSmD5I61s&t=186s), [4:09](https://www.youtube.com/watch?v=blDSmD5I61s&t=249s)
- Shortcuts used: F for frame, T for text, R for rectangle, P for pen, Shift+A for auto layout. [5:01](https://www.youtube.com/watch?v=blDSmD5I61s&t=301s), [6:30](https://www.youtube.com/watch?v=blDSmD5I61s&t=390s), [13:39](https://www.youtube.com/watch?v=blDSmD5I61s&t=819s), [15:41](https://www.youtube.com/watch?v=blDSmD5I61s&t=941s), [17:18](https://www.youtube.com/watch?v=blDSmD5I61s&t=1038s)
- The demo uses a 1440 px desktop frame, the Inter font, nav links at about 16 px and a 72 px heading. [5:01](https://www.youtube.com/watch?v=blDSmD5I61s&t=301s), [7:27](https://www.youtube.com/watch?v=blDSmD5I61s&t=447s), [11:09](https://www.youtube.com/watch?v=blDSmD5I61s&t=669s)

## Tactics

- **Practice on real sites.** Recreate a live website from a screenshot, so you copy a design that is known to work. [1:38](https://www.youtube.com/watch?v=blDSmD5I61s&t=98s)
- **Trace a locked reference.** Put the screenshot in a frame, drop its opacity to 20% and lock the layer, then build on top of it. [6:30](https://www.youtube.com/watch?v=blDSmD5I61s&t=390s)
- **Tune type against the reference.** Adjust size, weight, letter spacing and line height until the text matches. Set line height to "auto" after a size change, because the text tool keeps the last value. [7:27](https://www.youtube.com/watch?v=blDSmD5I61s&t=447s), [11:51](https://www.youtube.com/watch?v=blDSmD5I61s&t=711s)
- **Fixed-width text boxes.** Resize a text box to set a fixed width, so long text wraps. [12:37](https://www.youtube.com/watch?v=blDSmD5I61s&t=757s)
- **Resize without distortion.** Hold Shift or turn on "constrain proportions". Hold Shift with arrow keys for bigger steps. [10:27](https://www.youtube.com/watch?v=blDSmD5I61s&t=627s), [11:09](https://www.youtube.com/watch?v=blDSmD5I61s&t=669s)
- **Buttons with auto layout.** Wrap the label with Shift+A, then add a fill and corner radius. [13:39](https://www.youtube.com/watch?v=blDSmD5I61s&t=819s), [14:41](https://www.youtube.com/watch?v=blDSmD5I61s&t=881s)
- **Fill shapes with images.** Select a shape and pick an image in the Unsplash plugin to fill it. [16:21](https://www.youtube.com/watch?v=blDSmD5I61s&t=981s)
- **Reuse the logo by cropping.** Crop the reference screenshot down to the logo instead of rebuilding it. [18:48](https://www.youtube.com/watch?v=blDSmD5I61s&t=1128s)
- **Recolor with selection colors.** Select the frame and swap every color in it from one list. [19:31](https://www.youtube.com/watch?v=blDSmD5I61s&t=1171s)
