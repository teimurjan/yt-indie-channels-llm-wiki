# How To Create Gradients in Figma (Linear, Radial, Angular, Diamond)

## Summary

Tim Gabe explains the four gradient types in Figma: linear, radial, angular and diamond. Plain colors can look boring in UI design, and gradients add depth. You set every type from the fill dropdown. You then edit color stops, angle and size on the canvas.

## Key facts

- Figma has 4 gradient types: linear, radial, angular and diamond. [0:00](https://www.youtube.com/watch?v=BASF9O2_AFo&t=0s)
- Linear: colors run along a straight line. [0:00](https://www.youtube.com/watch?v=BASF9O2_AFo&t=0s)
- Radial: colors start at a center point and move out to the edges. [1:00](https://www.youtube.com/watch?v=BASF9O2_AFo&t=60s)
- Angular: colors move clockwise through 360 degrees around one point. [2:01](https://www.youtube.com/watch?v=BASF9O2_AFo&t=121s)
- Diamond: like radial, but the shape is a diamond or square, not a circle. [2:01](https://www.youtube.com/watch?v=BASF9O2_AFo&t=121s), [3:02](https://www.youtube.com/watch?v=BASF9O2_AFo&t=182s)

## Tactics

- **Switch the fill type.** In the fill panel, change "Solid" to Linear, Radial, Angular or Diamond. [0:00](https://www.youtube.com/watch?v=BASF9O2_AFo&t=0s)
- **Edit color stops on the canvas.** Drag the boxes on the gradient line to move stops. Click the line to add a stop. Select a stop and press Backspace to remove it. [1:00](https://www.youtube.com/watch?v=BASF9O2_AFo&t=60s)
- **Change angle, size and opacity.** Drag the handles to change the angle and size. Set color and opacity for each stop in the panel. [1:00](https://www.youtube.com/watch?v=BASF9O2_AFo&t=60s), [2:01](https://www.youtube.com/watch?v=BASF9O2_AFo&t=121s)
