## Summary

Jonathan Fishner is a developer and co-founder of ChartDB, an open-source tool that turns a database schema into an interactive diagram. Developers self-host it for free. The paid cloud version adds hosting and team features. ChartDB makes about $9K MRR, 16 months after its open-source launch (2026-02). One Show HN post on Hacker News brought thousands of engineers on the first day. Note: the auto captions often spell the product "Chartbrew" or "Charted Be". The description confirms the name is ChartDB.

## Tactics

- **Pivot to lower friction.** ChartDB needs no sign-up, no database access and no install. The user runs one "smart query" in their own client and pastes the JSON result. The visual result gives a fast wow effect. [3:27](https://www.youtube.com/watch?v=7vz6b_Ohdl0&t=207s), [9:38](https://www.youtube.com/watch?v=7vz6b_Ohdl0&t=578s)
- **Why the Show HN worked.** Developers like open source because they can test it with no sign-up. A unique wedge earns upvotes, and upvotes reach the front page. [4:51](https://www.youtube.com/watch?v=7vz6b_Ohdl0&t=291s)
- **Developer tools playbook, five steps:** [6:37](https://www.youtube.com/watch?v=7vz6b_Ohdl0&t=397s), [7:38](https://www.youtube.com/watch?v=7vz6b_Ohdl0&t=458s), [8:39](https://www.youtube.com/watch?v=7vz6b_Ohdl0&t=519s)
  1. Be the user. Build for yourself.
  2. Design for the persona's constraints. Developers want self-hosted tools with no sign-up wall and no sales calls.
  3. Start with a wedge, not the full vision. Iterate on feedback.
  4. Let usage show what to charge for. ChartDB was free at first. Users then asked for team use, so real-time collaboration became the paid feature.
  5. Market where the ideal customer already is: GitHub, Hacker News and self-hosted subreddits on Reddit.
- **Open source as the funnel.** Free downloads are the entry point. A small group then pays for the hosted cloud version. [13:46](https://www.youtube.com/watch?v=7vz6b_Ohdl0&t=826s), [14:41](https://www.youtube.com/watch?v=7vz6b_Ohdl0&t=881s)
- **Defend one core value.** The team ignored all else and made database visualization obvious. Then growth started. [11:57](https://www.youtube.com/watch?v=7vz6b_Ohdl0&t=717s)
