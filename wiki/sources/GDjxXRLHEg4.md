# 5 Figma Workflow Tips For UI Beginners

## Summary

Tim Gabe gives five Figma habits that save beginners time. Use auto layout even for simple pairs of elements. Learn a handful of shortcuts. Install plugins for icons, images and placeholder text. Use column grids from the start. Size everything on a 4 or 8 point system. Each tip is a basic version of a longer video he links in the shared Figma file.

## Key facts

- The video covers the tips in about 10 minutes, with a linked Figma file (2023-02). [0:00](https://www.youtube.com/watch?v=GDjxXRLHEg4&t=0s)
- Column grid defaults: 12 columns on desktop, 8 on tablet, 4 on mobile. [6:20](https://www.youtube.com/watch?v=GDjxXRLHEg4&t=380s)
- Spacing scale: 4, 8, 12, 16, 24, 32, 40, 48 px. [7:15](https://www.youtube.com/watch?v=GDjxXRLHEg4&t=435s)

## Tactics

- **Auto layout everywhere.** A plain group only lets you drag items by hand. Auto layout gives alignment, direction and spacing controls. Wrap even an avatar plus text, or two text fields, in auto layout. [0:52](https://www.youtube.com/watch?v=GDjxXRLHEg4&t=52s), [2:56](https://www.youtube.com/watch?v=GDjxXRLHEg4&t=176s)
- **Basic shortcuts.** A or F makes a frame, T makes text, R a rectangle, O an ellipse. Type numbers to set opacity: "6", "5" gives 65%. [3:40](https://www.youtube.com/watch?v=GDjxXRLHEg4&t=220s), [4:43](https://www.youtube.com/watch?v=GDjxXRLHEg4&t=283s)
- **Three plugin types.** For icons, use Lucide or a plugin with many icon styles. For images, use Unsplash or Pexels. For copy, use a Lorem Ipsum plugin. [5:03](https://www.youtube.com/watch?v=GDjxXRLHEg4&t=303s), [6:05](https://www.youtube.com/watch?v=GDjxXRLHEg4&t=365s)
- **Start with column grids.** Add a layout grid in the right panel and set it to columns. Do this even before you know all the details. [6:20](https://www.youtube.com/watch?v=GDjxXRLHEg4&t=380s)
- **Standard measurements.** A 4 or 8 point system replaces values such as 31 px or 57 px. Developers can then spot a mistake: 31 px is probably 32 px. [7:15](https://www.youtube.com/watch?v=GDjxXRLHEg4&t=435s), [8:18](https://www.youtube.com/watch?v=GDjxXRLHEg4&t=498s)

## Quotes
