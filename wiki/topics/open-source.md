This page collects what the sources say about open source as a business model and a growth channel.

## Definition

An open-source business publishes its code for free and charges for hosting, team features, enterprise licenses or listings around it. In these sources the free code is mainly a distribution channel to developers.

## Repeated patterns

### The free code is the funnel

- Free downloads are the entry point. A small group then pays for the hosted cloud version ([7vz6b_Ohdl0](../sources/7vz6b_Ohdl0.md), [13:46](https://www.youtube.com/watch?v=7vz6b_Ohdl0&t=826s)).
- Treat self-hosting as a free tier. Developers rarely pay, but they bring word of mouth, bug reports, blog posts and directory listings ([RPM4ImzcIFc](../sources/RPM4ImzcIFc.md), [7:34](https://www.youtube.com/watch?v=RPM4ImzcIFc&t=454s)).
- AI lets anyone build anything, so code has little value and brand wins ([RPM4ImzcIFc](../sources/RPM4ImzcIFc.md), [6:46](https://www.youtube.com/watch?v=RPM4ImzcIFc&t=406s)).

### Open source as a moat

- [Marc Seitz](../people/marc-seitz.md) lists four benefits. A free core is hard to undercut. There is no barrier to entry. The community adds R&D speed. Banks can audit the code ([F8i0kkrQ8_o](../sources/F8i0kkrQ8_o.md), [5:08](https://www.youtube.com/watch?v=F8i0kkrQ8_o&t=308s)).
- People copied [Postiz](../businesses/postiz.md) and hosted it as rivals. They gave up within weeks, because the creator owns the brand ([RPM4ImzcIFc](../sources/RPM4ImzcIFc.md), [9:37](https://www.youtube.com/watch?v=RPM4ImzcIFc&t=577s)).
- Open-source rules on GitHub cut upkeep. [Cursor Directory](../businesses/cursor-directory.md) needs about 3 hours a month ([LWPN-PAhtLA](../sources/LWPN-PAhtLA.md), [2:39](https://www.youtube.com/watch?v=LWPN-PAhtLA&t=159s)).

### How to make money

- Open core: free self-hosting, a paid hosted version, and paid enterprise licenses for advanced features ([F8i0kkrQ8_o](../sources/F8i0kkrQ8_o.md), [4:27](https://www.youtube.com/watch?v=F8i0kkrQ8_o&t=267s)).
- Let usage show what to charge for. ChartDB users asked for team use, so real-time collaboration became the paid feature ([7vz6b_Ohdl0](../sources/7vz6b_Ohdl0.md), [7:38](https://www.youtube.com/watch?v=7vz6b_Ohdl0&t=458s)).
- The biggest open-source revenue is self-hosted enterprise support ([RPM4ImzcIFc](../sources/RPM4ImzcIFc.md), [8:35](https://www.youtube.com/watch?v=RPM4ImzcIFc&t=515s)).
- Cursor Directory sells paid job listings and featured MCP listings ([LWPN-PAhtLA](../sources/LWPN-PAhtLA.md), [10:16](https://www.youtube.com/watch?v=LWPN-PAhtLA&t=616s)).

### Launch where developers are

- Show HN works because developers can test open source with no sign-up. A unique wedge earns upvotes ([7vz6b_Ohdl0](../sources/7vz6b_Ohdl0.md), [4:51](https://www.youtube.com/watch?v=7vz6b_Ohdl0&t=291s)).
- Link Show HN to the GitHub repo, not the website. A front-page post brings about 10,000 views ([RPM4ImzcIFc](../sources/RPM4ImzcIFc.md), [13:38](https://www.youtube.com/watch?v=RPM4ImzcIFc&t=818s)).
- Post to r/selfhosted each month. Use "I", not "we", and ask for a star ([RPM4ImzcIFc](../sources/RPM4ImzcIFc.md), [14:32](https://www.youtube.com/watch?v=RPM4ImzcIFc&t=872s)).
- Run all launch steps in one week to hit GitHub trending ([RPM4ImzcIFc](../sources/RPM4ImzcIFc.md), [15:34](https://www.youtube.com/watch?v=RPM4ImzcIFc&t=934s)).
- Build in public on X and LinkedIn. Papermark also joined Hacktoberfest ([F8i0kkrQ8_o](../sources/F8i0kkrQ8_o.md), [9:06](https://www.youtube.com/watch?v=F8i0kkrQ8_o&t=546s)). See [build in public](build-in-public.md).

### Prepare the repo like a landing page

- The README is the landing page. Call it "an open-source alternative to X" ([RPM4ImzcIFc](../sources/RPM4ImzcIFc.md), [10:35](https://www.youtube.com/watch?v=RPM4ImzcIFc&t=635s)). See [competitor alternatives](competitor-alternatives.md).
- Pick a license (MIT, Apache 2 or AGPL 3). Ship deploy docs and a Docker image, or developers churn ([RPM4ImzcIFc](../sources/RPM4ImzcIFc.md), [11:36](https://www.youtube.com/watch?v=RPM4ImzcIFc&t=696s)).
- Developers want self-hosted tools with no sign-up wall and no sales calls ([7vz6b_Ohdl0](../sources/7vz6b_Ohdl0.md), [6:37](https://www.youtube.com/watch?v=7vz6b_Ohdl0&t=397s)).

## Concrete examples

- [ChartDB](../businesses/chartdb.md): about $9K MRR, over 21K GitHub stars and 250K developers in a year (2026-02) ([7vz6b_Ohdl0](../sources/7vz6b_Ohdl0.md), [1:36](https://www.youtube.com/watch?v=7vz6b_Ohdl0&t=96s)).
- [Papermark](../businesses/papermark.md): $75K MRR, about 1,000 paying customers, 60 contributors and 7K stars (2025-08) ([F8i0kkrQ8_o](../sources/F8i0kkrQ8_o.md), [10:08](https://www.youtube.com/watch?v=F8i0kkrQ8_o&t=608s)).
- [Postiz](../businesses/postiz.md): $17K MRR from 472 subscribers, 19% monthly churn (2026-01) ([RPM4ImzcIFc](../sources/RPM4ImzcIFc.md), [2:25](https://www.youtube.com/watch?v=RPM4ImzcIFc&t=145s)). Over 25K stars and 5M downloads ([RPM4ImzcIFc](../sources/RPM4ImzcIFc.md), [0:14](https://www.youtube.com/watch?v=RPM4ImzcIFc&t=14s)).
- [Cursor Directory](../businesses/cursor-directory.md): about $34K to $35K/month at a 99.8% gross margin (2025-11) ([LWPN-PAhtLA](../sources/LWPN-PAhtLA.md), [0:21](https://www.youtube.com/watch?v=LWPN-PAhtLA&t=21s)).

## Disagreements

> Conflict: [F8i0kkrQ8_o](../sources/F8i0kkrQ8_o.md) holds advanced features back for paid enterprise licenses (open core). [RPM4ImzcIFc](../sources/RPM4ImzcIFc.md) makes the paid cloud product the same as the open-source code and sells hosting and support instead.
